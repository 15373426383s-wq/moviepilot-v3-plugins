# 2026-10-28

## MoviePilot V3 洗版插件骨架
- 用户在绿联 NAS (UGOS Pro) 的 Docker 中跑 MoviePilot，有自己的 GitHub 仓库用于发布插件。
- 生成了 V3 插件骨架：目录 `plugins.v3/myplugin/`（主类 `MyPlugin` 在 `__init__.py`）、仓库根 `package.v3.json`、插件 `README.md`。
- 插件功能：定时（Cron）扫描订阅的电影/电视剧，发现更优画质版本时洗版（重新下载）；含配置页（启用/目标画质/周期/试运行）和详情页。
- `wash()` 核心逻辑目前是骨架，需在 `SubscribeChain`/`SearchChain`/`DownloadChain` 上按目标 V3 宿主实际签名补全。
- 用户偏好：极简、最小可用，明确反对"花活"（多余装饰/复杂功能）。
- 加载方式：推到仓库 `main` 分支，填 `PLUGIN_MARKET`；本地联调用 `PLUGIN_LOCAL_REPO_PATHS` + `PLUGIN_AUTO_RELOAD=true` + `DEBUG=true`。
