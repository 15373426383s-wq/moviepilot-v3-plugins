## 安装

1. 打开 MoviePilot →「设置」→ 找到插件市场配置项 `PLUGIN_MARKET`（或在插件市场页面添加仓库）。
2. 填入本仓库地址：

   ```
   https://github.com/15373426383s-wq/moviepilot-v3-plugins
   ```

   多个仓库用英文逗号分隔。
3. 保存后进入「插件市场」，刷新即可看到「洗版自用」，点击安装。
4. 安装完成回到「已安装插件」列表，打开配置页。

## 洗版自用 · 快速开始

首次使用建议按这个顺序，避免一上来就下错东西：

1. **保持「试运行」为开**（默认就是开），点详情页「立即洗版一次」。
2. 打开「数据」页看运行记录，确认日志符合预期：
   - 有没有正确识别出「当前版本」；
   - 「发现更高版本」的对象是不是你真想要的；
   - 分集/全集的判断对不对。
3. 确认无误后**关闭「试运行」**，才会真正搜索并下载。
4. 之后按需调整：
   - 想安静点：通知选「每次运行汇总」；
   - 想更省站点请求：调大「每个订阅之间的间隔」、调小「每轮最多处理订阅数」；
   - 想更早收工：「封顶 · 分辨率」设为 4K（默认），或再多设来源等维度。

详细说明见 [`plugins.v3/washupgrade/README.md`](plugins.v3/washupgrade/README.md)。

## 注意事项

- 插件只调用 MoviePilot 自己的搜索/下载/通知链，**不会**直连任何站点或 Telegram；站点账号、下载器、通知渠道都在 MoviePilot 里配。
- 一次洗版会对每个订阅遍历所有已配置站点。订阅多时请务必设置请求间隔与每轮上限，否则容易被站点判定为爬虫。建议同时在 MoviePilot「站点管理」里给站点配置流控，两层叠加。
- 自定义打分模式依据**资源标题文本**匹配画质，命名不规范的资源可能漏判某一维度（只影响该维度得分，不影响其它维度）。
