# 洗版自用 (WashUpgrade)

定时触发 MoviePilot 订阅刷新，对开启了**最佳版本**的订阅自动下载更优画质（洗版）。

适用宿主：**MoviePilot v3.2.1+**（已针对 v3.2.1 的 `SubscribeChain` Facade 验证）。

## 原理

MoviePilot 的「洗版」本质是订阅的 `best_version`（最佳版本）：宿主每次刷新订阅时，
会重新拉取站点种子并匹配，对开启最佳版本的订阅自动下载更优画质版本。

因此本插件**不重造搜索 / 下载 / 画质比对逻辑**，只负责按 Cron 周期调用宿主的
`SubscribeChain().refresh()` 触发刷新，把「画质目标」交还给每个订阅自身的设置
（最佳版本 + 画质 / 分辨率 / 特效）。这是最小可用、最不易出错的做法。

> 也就是说：要洗版哪个资源，请在该订阅里打开「最佳版本」并按需设置画质/分辨率/特效；
> 本插件负责「什么时候去扫一遍」。

## 配置项

| 配置 | 说明 | 默认 |
| --- | --- | --- |
| 启用洗版 | 总开关（同时控制定时任务是否注册） | 关 |
| 洗版范围 | 全部订阅 / 仅电影 / 仅电视剧 | 全部 |
| 扫描周期 | Cron 表达式 | `0 4 * * *`（每天 4 点） |
| 试运行 | 只记录不真正刷新，**首次建议保持开启** | 开 |

## 使用步骤

1. 先在 MoviePilot 里给想要洗版的订阅打开「最佳版本」，并设置好画质目标。
2. 安装本插件，打开「启用洗版」，确认「试运行」为开，保存。
3. 观察日志出现 `[洗版] [试运行] ...`，确认插件按周期正常触发。
4. 确认无误后，把「试运行」关掉，插件到周期就会真正触发洗版刷新。

## 目录结构

```
plugins.v3/washupgrade/__init__.py   # 插件主类 WashUpgrade
package.v3.json                       # 市场索引（仓库根目录）
```

## 发布

1. 推到 GitHub 仓库的 `main` 分支。
2. 在 MoviePilot 配置项 `PLUGIN_MARKET` 填入仓库地址（多个用逗号分隔）。
3. 插件市场即可发现并安装；修改版本号会触发更新提示。

## 注意

- 发布前请确认 `__init__.py` 的 `plugin_version`、`package.v3.json` 的 `version`、
  以及 `history` 顶部版本三者一致。
- 把 `WashUpgrade`、作者 `your-name` 与链接替换为你自己的标识（目录名需为类名小写 `washupgrade`）。
- 本地联调：`PLUGIN_LOCAL_REPO_PATHS` 指向本地仓库、`PLUGIN_AUTO_RELOAD=true`、`DEBUG=true`。
