# 洗版自用 (WashUpgrade)

**洗版编排插件**：定时（或手动）对目标订阅触发 **MoviePilot 原生的「最佳版本」搜索**，由宿主完成洗版。

适用宿主：**MoviePilot v3.2.1+**。

## 设计思路（v1.3.0 起）

MoviePilot 自身已经有一套完整的洗版能力：

- 全局「**洗版评分规则**」页（分辨率 / 片源 / 视频编码 / 音频编码 / HDR 等维度优先级，可拖拽排序）；
- 每个订阅里的「**最佳版本**」开关，以及对应的画质 / 分辨率 / 特效目标；
- 订阅搜索会自动按上述规则找更优版本并下载（电视剧还能处理分集 / 全集）。

所以本插件**不再重复实现评分与下载**，只做一个轻量编排器：挑出要洗版的订阅，按你设定的周期去触发宿主的原生最佳版本搜索。
这样评分规则、画质目标、分集/全集处理全部由你已经在 MoviePilot 里配好的规则决定，不冲突、不重复。

## 工作流程

1. 读取全部订阅。
2. 按配置过滤：仅保留「已开启最佳版本」的订阅（可放宽），并按范围（全部 / 仅电影 / 仅电视剧）筛选。
3. 调用 `SubscribeChain().search(sids=..., manual=True)` 批量触发这些订阅的原生最佳版本搜索。
   - 真正的搜索 / 评分 / 匹配 / 下载由 MoviePilot 完成，资源来源为你已配置的 PT 站点。
4. 试运行模式下只记录「将触发哪些订阅」，不真正搜索，便于先确认范围。

## 配置项

| 配置 | 说明 | 默认 |
| --- | --- | --- |
| 启用评分洗版 | 总开关（同时控制定时任务是否注册） | 关 |
| 洗版范围 | 全部订阅 / 仅电影 / 仅电视剧 | 全部 |
| 仅对开启「最佳版本」的订阅洗版 | 收窄到明确要洗版的订阅（建议开） | 开 |
| 扫描周期 | Cron 表达式 | `0 4 * * *`（每天 4 点） |
| 试运行 | **只记录将触发的订阅、不真正搜索**，首次务必保持开 | 开 |

> 评分规则与画质/特效目标请在 MoviePilot 的「洗版评分规则」页和订阅的「最佳版本」中设置——本插件只负责按周期触发它们。

## 日志 / 运行记录

- 本插件同时写入宿主插件日志（`logs/plugins/washupgrade.log`，在插件「查看日志」按钮里看）与**内存活动缓存**。
- 内存缓存会在插件「数据」页（详情页）以「运行记录（最近 30 条）」展示，即使插件日志文件暂不可读也能看到运行轨迹。
- 每次扫描、每个将触发的订阅、触发结果都会记录。

## 使用步骤

1. 在 MoviePilot 中配置好全局「洗版评分规则」页，并给要洗版的订阅开启「最佳版本」、设好画质/特效目标。
2. 安装本插件，打开「启用评分洗版」，保持「试运行」为开，保存。
3. 到周期（或等下次扫描）后，打开插件「数据」页，确认列出的是你期望的订阅。
4. 确认无误后关闭「试运行」，到周期时就会真正触发最佳版本搜索与下载。

## 已知限制（v1.3.0）

- 洗版效果完全取决于你在 MoviePilot 里配置的评分规则与订阅最佳版本目标；插件本身不评分、不筛选画质。
- 对比/去重、分集/全集处理均由宿主负责；插件不维护额外的内存基线。
- 触发是「批量提交订阅搜索」，具体搜索节奏与并发受宿主订阅搜索队列控制。

## 发布 / 加载

1. 推到 GitHub 仓库的 `main` 分支（本仓库：`moviepilot-v3-plugins`）。
2. 在 MoviePilot 配置项 `PLUGIN_MARKET` 填入仓库地址（多个用逗号分隔）。
3. 插件市场即可发现并安装。

> 发布前确认 `__init__.py` 的 `plugin_version`、`package.v3.json` 的 `version`、`history` 顶部版本三者一致。
> 把 `WashUpgrade`、作者 `your-name` 与链接替换为你自己的标识（目录名需为类名小写 `washupgrade`）。
